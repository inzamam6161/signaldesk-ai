# SignalDesk AI

SignalDesk is a customer-intelligence dashboard built with Next.js, React and TypeScript. Its current analysis route uses deterministic processing and simulates an external AI provider; production model integration is planned.

## Highlights

- Responsive dashboard and mobile navigation
- AI prompt interaction with loading and result states
- Searchable customer feedback
- Dynamic date-range chart
- Keyboard command menu (`/` and `Esc`)
- Accessible controls and reduced-motion support
- Typed component and data boundaries

## Start

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.
